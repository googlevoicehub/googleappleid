## 稳定可靠的 Apple ID 具有如下特点
1. Apple ID 账号足够老、比如注册时间超过10年以上。
2. 手工注册的账号、而非批量脚本注册的账号。
3. 绝版账号、比如后缀为 `@me.com` 或者 `@mac.com`。
4. 开启二次认证并且绑定对应地区的手机号、比如美国🇺🇸地区绑定美国手机号、日本🇯🇵地区绑定日本手机号、香港🇭🇰地区绑定香港手机号。
5. 不出借、不共享账号给他人登录。


## 不稳定可靠的 Apple ID 具有如下特点
1. 账号太新、比如刚注册不到1个月、这种账号很容易让手机被锁、或者账号无法退出。
2. 脚本批量注册的Apple ID。
3. 共享的苹果 Apple ID 账号、多人共同使用很容易封号。
