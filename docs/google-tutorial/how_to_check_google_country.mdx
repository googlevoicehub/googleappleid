## 查看谷歌账号国家地区
1. 浏览器登录你的谷歌账号
2. 点击直达链接: https://policies.google.com/terms?hl=zh-CN&fg=1
3. 找到【服务条款】- 【国家/地区版本：】
4. 我的账号显示是美国

## 如何修改谷歌账号国家地区
1. 点击直达链接: https://policies.google.com/faq?hl=zh-CN&fg=1#associated-country
2. 找到【常见问题解答】页签、页面滚动到【确定与您账号关联的国家/地区】
3. 点击请提交[关联国家/地区更改](https://policies.google.com/country-association-form?hl=zh-CN&fg=1&source=policies-site)请求。https://policies.google.com/country-association-form?hl=zh-CN&fg=1&source=policies-site
4. 按照提示修改国家并提交即可

## 注意事项
1. 提交之前、必须把账号挂特定国家的IP 1个月以上、否则很大概率无法通过国家地区的修改申请
2. 长时间挂同一个国家地区的IP使用、比如美国地区、那么谷歌会定期检测并自动更换到对应的国家地区即美国地区。
